# Campus Hub

Учебное приложение Expo + TypeScript для iOS/Android (Expo Go). Четыре вкладки: главная, задачи, расписание, объявления. Готовый код предоставлен как учебный пример для разбора студентами.

## Установка в существующий CampusHub

1. Остановите Expo: Ctrl+C.
2. Скопируйте из архива `App.tsx`, папку `src`, папку `docs`, `README.md` и `.gitignore` в существующий проект. Подтвердите замену App.tsx. Существующие package.json, package-lock.json, app.json и index.ts оставьте: зависимости добавят команды ниже.
3. Выполните в PowerShell:

```powershell
cd C:\Users\blenz\CampusHub
npm install @react-navigation/native@^7 @react-navigation/bottom-tabs@^7 @react-navigation/native-stack@^7
npx expo install expo-sqlite react-native-screens react-native-safe-area-context
npx tsc --noEmit
npx expo start --clear
```

Сканируйте QR обычной камерой iPhone, откройте в Expo Go. При проблеме старого глобального CLI используйте `.\node_modules\.bin\expo.cmd start --clear`.

## Установка из этого архива как отдельного проекта

В корне распакованной папки выполните `npm install`, затем `npm run setup`, затем `npm run typecheck` и `npm start`. Setup добавляет native-зависимости с версиями, выбранными установленным Expo SDK. После setup package.json и package-lock.json нужно сохранить в Git.

Базовые версии взяты из рабочего проекта преподавателя: Expo ~57.0.27, React 19.2.3, React Native 0.86.3, TypeScript ~6.0.3. Версии native-модулей подбирает `expo install`. Web-версия SQLite отдельно не настроена: показывайте приложение на телефоне.

## Структура

| Каталог | Назначение |
|---|---|
| src/screens | Экраны приложения и форма задачи |
| src/components | Переиспользуемые кнопки, карточка задачи |
| src/navigation | Нижние вкладки и stack формы |
| src/context | Общее состояние задач, загрузка, ошибки |
| src/services | REST API и проверка структуры ответа |
| src/database | SQLite и параметризованные CRUD-запросы |
| src/types | Типы данных и параметры навигации |
| src/theme | Цвета и стили |
| src/data | Демонстрационное расписание |

## Соответствие темам

| ЛР | Реализация |
|---|---|
| 1 | Expo, TypeScript, запуск на телефоне |
| 2 | Text, View, TextInput, Pressable, FlatList, карточки, формы |
| 3 | React Navigation: четыре вкладки и переход в редактор с taskId |
| 4 | useState, Context, поиск, фильтры, общий счётчик выполненных задач |
| 5 | fetch, useEffect, GET, HTTP-проверка, тайм-аут, отмена запроса, повтор |
| 6 | SQLite: создание таблицы, INSERT, SELECT, UPDATE, DELETE |

Это соответствие известным темам курса, а не дословное воспроизведение презентации. Для ЛР6 выбран вариант SQLite; Firebase и авторизация не входят в этот комплект.

## Проверка перед видео

1. Добавьте задачу «Подготовить ЛР6», предмет «Мобильные приложения», высокий приоритет.
2. Измените название, отметьте готовой; на главной должен измениться счётчик.
3. Проверьте поиск и фильтры.
4. Перезагрузите проект в Expo Go: задача должна остаться.
5. Создайте вторую задачу и удалите её с подтверждением.
6. Попробуйте сохранить пустое название: получите подсказку.
7. Переключите дни расписания; в пятницу показано пустое состояние.
8. Откройте объявления и нажмите «Обновить»: придут 10 записей JSONPlaceholder.
9. После загрузки приложения отключите интернет и нажмите «Обновить»: должна появиться ошибка; ранее загруженные записи останутся на экране этой сессии. Верните интернет и повторите.

Задачи хранятся только в SQLite на текущем устройстве, не синхронизируются и не загружаются в GitHub. Расписание вымышленное. Объявления — тестовые тексты стороннего сервиса, не реальные новости университета. Внешний сервис может быть недоступен.
